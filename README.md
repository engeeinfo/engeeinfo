### 🚀 Professional Summary

I am a hybrid engineer bridging the gap between **bare-metal hardware precision** and **fluid user interfaces**. With strong hands-on experience in Embedded C/C++ and FPGA design, I specialize in building full-stack IoT solutions—from writing the firmware drivers to developing the cross-platform Flutter mobile app that controls them.

* **Core Focus:** Low-level systems, Real-time applications (RTOS), and Hardware-Software Integration.
* **Current Pursuit:** Advanced Flutter UI/UX, Cross-platform deployment, and Embedded AI.
* **Protocol Expertise:** SPI, I2C, UART, CAN, USB, AXI, APB.
